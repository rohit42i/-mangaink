# Changelog

## 1.0.1-stage1

- Replaced the Activity-based UI with a custom dark Jetpack Compose and Material 3 theme.
- Centralized UI and overlay commands in SessionController and StateFlow.
- Added a draggable, edge-snapping floating panel and a running screen border.
- Added segmented gesture callbacks, a 16 ms inter-segment gap and a stop dispatch gate.
- Added the manual test-result dialog, in-memory MI_GESTURE viewer and volume-down long-press stop.
- Added the permission-status checklist, Settings screen, device test record and Stage 1 privacy checks.
