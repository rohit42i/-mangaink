# Changelog

## 1.1.0-alpha repair

- Restored complete-page image import and local image processing.
- Added full-page and drag-selected-area scan modes.
- Added outline extraction, path preview, scan metrics and tuning controls.
- Added four-corner calibration and projective page mapping.
- Connected extracted paths to the shared accessibility gesture controller.
- Added required visible test stroke before page tracing.
- Added working Test/Start, Pause/Resume, Stop, More, Minimize and Clear actions.
- Fixed long-line segmentation to split by arc length and preserve continuous coordinates.
- Added in-app GitHub update checks, signed release downloading, SHA-256 verification and Android package installation handoff.
- Added release publishing on each push to the repair branch.
- Added algorithm tests and revised device verification instructions.

## 1.0.1-stage1

- Added the Jetpack Compose interface, shared session controller and Stage 1 gesture proof.
